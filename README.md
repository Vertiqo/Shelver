Shelver is intended to become a Blu-Ray Archive for me to keep track of which movies i already own and some quick information and facts about each movie i own.
Right now its a small Python commandline tool that supports Adding New Entries as a series of user inputs and saving them as a list of dictionarys in a JSON file.

Adding, Searching and Editing entries is currently possible.
New entries are guarded against having a Blank title or a malformed entry for the release year for example.

Shelver for now is very basic as it was made as "first own project" for the backend developer career path of Boot.dev
Future releases are planned to include features like parsing information from the web, a GUI, coverart etc.
